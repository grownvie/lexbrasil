🔑 Token de acesso do GitHub

Sem autenticação, a API do GitHub permite 60 requisições por hora por IP — o suficiente para navegar, mas pode acabar em sessões longas. Com um token pessoal (escopo public_repo), o limite sobe para 5.000/hora.

O token fica salvo somente no seu navegador (localStorage) e é enviado apenas para api.github.com. Você pode apagá-lo a qualquer momento.

Sobre o LexBrasil

Navegador não oficial · Código aberto

O LexBrasil é uma interface de leitura e pesquisa sobre o repositório ctresb/leis, que reúne 323.849 normas brasileiras em Markdown: a Constituição Federal, a legislação federal de 1822 até hoje e a de 25 estados e do Distrito Federal, cada arquivo com cabeçalho estruturado (ementa, data, situação, URN) e link para a origem oficial.

  • Busca por número: informe o número e o ano — o sistema localiza o arquivo no repositório e abre o texto vigente.
  • Busca por tema: um índice curado das principais leis federais, pesquisável por título, ementa e palavras-chave.
  • Texto integral: para busca em todo o conteúdo das 323 mil normas, usamos a busca de código do GitHub (requer conta no GitHub).
  • Navegação: toda a árvore de pastas do acervo é carregada diretamente da API do GitHub.

⚠️ Os textos têm caráter informativo e não substituem a publicação no Diário Oficial. São conversões automáticas e, em parte do acervo, OCR de PDF escaneado. Confira sempre a fonte indicada no cabeçalho da norma.

Pendências conhecidas do acervo: PR e RJ ainda sem coleta; lacunas parciais em AC, TO, RN, RS, ES, SE e MG (detalhes no README do repositório).
